# Scene implementation brief

You own only dist/scene.js and dist/models.js in this project. Build a polished lightweight mobile portrait daytime highway 3D game view. Do not spawn subagents or publish. Use Three.js 0.180.0 vendored module at ./vendor/three.module.js (parent installs). Return compact implementation report in docs/scene-report.md. No other file changes.

Export createScene(canvas) from scene.js returning {render(state,dt),resize()}. Render may run before game starts. State is read-only: phase ready/running/paused/over; time seconds; distance meters; speed km/h; altitude meters; thrusting boolean; events array. Each event: id, kind front/rear/battery, x meters, z meters positive ahead, height, length, width, age seconds, resolved boolean, sourceX number, sourceZ number. Positive z is forward in simulation, map to scene negative Z. Player x=0 z=0, bottom of chassis at state.altitude + road clearance. Player reference dimensions length 4.6 m, width 1.9 m, total height 1.1. MPV width2.0 length5.5 height2.0, sedan width1.85 length4.6 height1.45. Battery dimensions width1.8 length1.8 height0.35. Source SUV width2.0 length4.5 height1.9; at sourceX, sourceZ. Road lanes center x=-4,0,4; asphalt boundaries ±6.2.

Camera third-person chase, portrait tall phone: player in lower center but above bottom 120px controls; clear far road horizon. FOV about55-65. Daytime blue sky, distant sage green hills, dry asphalt, cream guardrails, white dashed lane lines, grass, procedural trees and understated kilometer markers. Want stylish sunlit natural palette, subtle shadows/tone mapping, antialiasing. Cap pixel ratio 1.6-2.0; pool scenery, avoid spawning allocations per frame. No external image requests.

Vehicle models must not be generic cubes: tapered aerodynamic white Roadster (new 2026 reference), gold glass canopy, black lower body/diffuser, fine red rear lightbar and silver multi-spoke wheels. Main chase view prioritize rear three-quarter silhouette. MPV references 尊界V800 with long high cabin, black+champagne two tone, distinct imposing grille/headlights (rear mirror important). SUV references iCAR03T with boxy silhouette, wide dark arches, upright glass, vertical lights, rear square storage box. Ordinary braking sedan has obvious glowing brake lamps. Use geometry/material quality, beveled/rounded boxes via custom shapes if efficient; avoid addon imports unless parent agrees.

Jets are cold-gas white/icy blue plumes downward from player when thrusting (not flame exhaust). Ground shadow remains on road while player rises. Scene follows simulation altitude; don't animate bogus second altitude.

Rear mirror: #mirror-view DOM is reserved for rear viewport. Render via renderer.setScissor/setViewport using its bounding rect relative to canvas; rear camera looks backwards from player vicinity to show approaching MPV. In main scene, rear vehicle may briefly be behind camera then passes under player. Keep mirror rendering useful regardless state. Mirror CSS handled by parent. Scissor cleared per view. Canvas covers the game shell (portrait max520px or potentially desktop full viewport - parent chooses portrait max520px). Resize per canvas client rect, not window.

For battery kind render the source SUV in adjacent lane and battery at event x/z. Warn sparkle/smoke before ejection: event age<0.8; battery hidden until age>=0.8; sourceX is fixed ±4. SourceZ provided by simulation. No physics in renderer. Event after resolved can remain visible driving away; respect array removals. All event transforms should be explicit.

Do not change signatures; report concerns. Parent handles simulation tests, UI, dependencies, browser QA and deployment.
