# Roadster · 公路飞跃

手机竖屏网页小游戏：白天三车道高速公路、滑动变道、喷气起飞躲避危险。

## 怎么玩

- 开始页选择模式：普通模式比原版慢 20%，从 112 km/h 逐渐加速到 320 km/h；喷气模式保持原版 140→400 km/h 的速度曲线，车尾横排四个喷口自动喷出白色气雾，尾翼同时开始平滑抬升、倾转展开。尾翼仅在喷气模式出现，暂停时冻结展开姿态，重开时重新播放。两者无须额外按键，也不消耗起飞和侧翻的气量。
- 在画面左右滑动切换一条车道；按住底部按钮起飞，松手降落。支持同时滑动与起飞。电脑方向键或 A/D 变道，空格起飞。
- 地面自动攒气，喷气持续耗气。气量耗尽后松手，落地恢复。
- 空中每切换一条车道，侧向喷气并完成 360° 侧翻，额外消耗 25 气量；不足 25 时无法空中变道。翻滚完成后可再次变道。地面和货车车厢顶变道免费。
- 危险都来自路上的车，平均三四秒就来一次，有时前后两个接连而来：
  - 最常见的是前车急刹，刹车灯会频闪、车头下沉；普通减速时刹车灯只是常亮。
  - 后方刹车失灵的车会鸣笛冲来，要看后视镜。
  - 邻车打双闪急停，随后弹出电池包。
  - 前方问界 M9 外观的 SUV 悬挂断裂“崴脚”，一角塌下，拖着火花急停在本车道。
  - 路边抛锚的 M9 打着双闪、车后摆着三角警示牌，半停在最外侧车道上。
- 每种情况第一次出现时有一句提示，之后只能看车灯、火花，听喇叭，看后视镜判断。普通车也会打转向灯并线到你前方。
- 路上以轿车为主，普通轿车约占随机车流的 40%，参考官方卡布里蓝的小米 SU7 风格路人车约占 8%，采用低趴溜背、全景玻璃、水滴头灯、环形尾灯和五瓣轮圈；也有 SUV、MPV 和大货车。大货车车厢顶是平的，可以飞上去落在车厢上，站在上面和在地面一样攒气，开过车头或变道就落回路面。高度不够撞上车厢，也算撞车。
- 车速越高，镜头越广、风线越密、风声越响。飞行上限 8 m。普通车流会自己变道、跟车刹车；车辆之间会真实碰撞，刹车失灵的车撞上前车后两车打着双闪滑行撞停，事故车也会成为障碍。每行驶 10 m 得 1 分，无限时长。
- 切换后台自动暂停。模式选择、各模式的最佳距离与静音设置保存在当前浏览器。旧版的最佳距离归入喷气模式；再来一局会保留本局模式，返回起点可重新选择。
- 主页右上角的圆形音符按钮位于扬声器按钮下方，单独控制背景音乐；扬声器按钮控制音效，各自记住设置。音乐默认开启，首次点击开始游戏后播放，也可在主页直接点击音乐开关试听；暂停、继续倒数或切到后台时暂停，继续后从原位置播放，播完循环。

车型外观为风格化参考，危险事件为虚构游戏设定。SU7 的轮廓、头尾灯和轮圈参考[小米官方等比例车模展示](https://www.mi.com/global/product/xiaomi-su7-1-18-die-cast-model-car/)，车漆参考[SU7 官网卡布里蓝展示](https://www.xiaomiev.com/su7)近似调色；M9 的银蓝双色、车灯与 SUV 轮廓参考[鸿蒙智行官方外观展示](https://hima.auto/wenjie/m9-new/)；四个尾部喷口与主动空气动力学造型参考 [Roadster 官网](https://www.tesla.com/roadster?redirect=no)，展开过程为游戏动画；侧翻动作参考 [Roadster 发布会视频](https://www.youtube.com/watch?v=qt5p-_tE8d0&t=598s)中的姿态控制喷气概念。

## 本地运行

安装 Python 后，在本文件所在目录运行：

```text
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

在浏览器访问 http://127.0.0.1:4173/ 。ES 模块需要 HTTP 服务，不能直接双击 HTML 文件运行。部署只需上传 dist 目录中的静态文件，无须构建。Three.js 通过国内 [BootCDN](https://www.bootcdn.cn/three.js/) 加载，运行时需联网。

Three.js 固定为 0.180.0，统一在 `dist/index.html` 的 import map 中配置。主模块和其依赖的 `three.core.js` 均从同一 CDN、同一版本加载。

## 文件

- `dist/game.js`：固定步长模拟、起降与燃料、危险生成和碰撞。
- `dist/scene.js`、`dist/models.js`：三维场景、车辆和后视镜。
- `dist/app.js`、`dist/audio.js`：触屏界面、暂停、记录和声音。
- `dist/audio/bgm.webm`：从用户提供的音频提取的完整音轨，约 3 分 7 秒、Opus 单声道（32 kbps），约 0.87 MB；头尾加入短淡入淡出。音频随静态网站一起部署，无须外部音乐服务。
- `dist/vendor/THREE-LICENSE.txt`：Three.js 的 MIT 许可证。
- `tests/game-v2.test.mjs`、`tests/modes.test.mjs`、`tests/su7.test.mjs`：游戏规则、模式与 SU7 车流测试，运行 `npm test`。

浏览器需支持 WebGL 2。没有账号、广告或后台数据收集。


## 验证

`npm test` 共 53 项规则测试，包括：

- 五种危险各自的地面碰撞、飞越和变道避让，以及信号到接触的时间。
- 急刹刹车灯频闪，崴脚车拖停且不离开本车道，路边抛锚车停在雾里、司机绕行。
- 落上货车车厢、在上面攒气再落回路面，以及车流里 SUV 的比例。
- 空中变道的 25 气量扣除、临界值和不足时拒绝变道，翻滚防重复扣气、暂停与重开，以及地面和货车顶免费变道。
- 车辆间碰撞与滑行停车，司机绕开事故车，普通车打灯并线且留足反应时间，撞车后的滑行，新车只在远处出现。
- 12 组随机车流在高车速下各 3 分钟的自动驾驶，其中急刹是最常见的危险。
- 两种速度曲线、不同帧率的距离一致性、模式切换与重开、自动尾喷不占用飞行气量；普通模式另外用 8 组种子从开局或接近顶速各跑 3 分钟，检查危险预警和顶速碰撞。
- SU7 从开局加入车流、约 8% 的生成占比及蓝色车漆，普通轿车约 40% 的占比，两种模式在 30/60/120 Hz 下的碰撞一致性与飞越净空。

原版速度曲线另用 48 局、每局 5 分钟的自动驾驶抽查（一半从最高速开局），全部存活。浏览器在桌面 Chromium 的手机尺寸模拟（390×844、375×667）中检查过双指起飞与变道、25 气量扣除、不足时提示、侧翻完成及贴地净空、M9 崴脚画面。

两种手机尺寸还检查了模式选择、独立纪录与旧纪录读取、刷新后保留模式、四喷口与四股气雾对齐、尾翼连续展开及暂停/碰撞冻结、重开复位、普通模式隐藏尾翼与尾喷，以及首次尾喷和尾翼展开不再新增着色器编译。

翻滚渲染另检查了物理步进之间的连续姿态、暂停时姿态冻结、贴地翻滚中段不起伏、落上货车顶时无高度突跳、侧喷气渐变交接，以及首次翻滚不再新增着色器编译。以上为桌面浏览器模拟，尚未在真实手机上测试性能。

音乐在两种手机尺寸下检查了独立音效开关、用户手势后播放、保存开关、暂停和倒数期间停止、续播与整曲循环；音频请求失败或存储不可用时仍能游戏。SU7 另检查了前后侧视图、蓝色车漆、刹车灯和尾部光晕、两侧转向灯与双闪、轮胎转动、实例间共享几何和独立灯材质，以及回池复用后恢复灯光状态。
