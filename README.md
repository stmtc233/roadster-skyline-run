# Roadster · 公路飞跃

一款面向手机竖屏的 Three.js 无尽公路小游戏。驾驶 Roadster 风格跑车，在白天的三车道高速公路上滑动变道、喷气起飞，越过越来越密集的车流。

车速随时间提高，没有时长限制；每行驶 **10 m 得 1 分**，撞车后结算。本地保存两种模式各自的最佳距离。

[GitHub 仓库](https://github.com/xiaoluuu233-star/roadster-skyline-run) · [作者 B站主页](https://space.bilibili.com/350724158)

## 快速开始

安装 Git 和 Python 3，在终端运行：

```shell
git clone https://github.com/xiaoluuu233-star/roadster-skyline-run.git
cd roadster-skyline-run
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

打开 [http://127.0.0.1:4173/](http://127.0.0.1:4173/)。如果已下载项目，只需在仓库根目录执行最后一条命令。

项目是纯静态网页，无须安装 npm 依赖或执行构建。也可以运行 `npm run dev` 启动相同的 Python 服务。页面使用 ES 模块，需要通过 HTTP 访问，不能直接双击 HTML 文件。

## 怎么玩

### 两种模式

| 模式 | 起步 → 最高时速 | 车尾效果 |
| --- | --- | --- |
| 普通模式 | 112 → 320 km/h | 无尾部喷气和主动尾翼 |
| 喷气模式 | 140 → 400 km/h | 四个尾部喷口自动喷气，尾翼同时平滑展开 |

普通模式的速度曲线比喷气模式低 20%。尾部喷气无需操作，也不消耗飞行气量；尾翼仅在喷气模式出现，暂停时冻结展开姿态，重开时重新展开。

模式在开始页选择，重开保留当前模式，返回主页后可重新选择。两种模式共用起飞、侧翻和计分规则，分别记录最佳成绩；旧版历史成绩归入喷气模式。

### 操作与燃料

| 操作 | 手机触屏 | 电脑键盘 |
| --- | --- | --- |
| 左右变道 | 向左 / 向右滑动，一次切换一条车道 | ← / → 或 A / D |
| 起飞 | 按住底部起飞按钮 | 按住空格 |
| 降落 | 松开起飞按钮 | 松开空格 |
| 暂停 | 点击右上角暂停按钮 | Esc 或点击暂停按钮 |

支持一根手指按住起飞、另一根手指滑动变道。切到后台或窗口失焦会自动暂停，继续时倒数 3 秒。

| 规则 | 数值 |
| --- | --- |
| 气量上限 | 100 |
| 地面、货车顶恢复气量 | 每秒 +20 |
| 持续起飞消耗 | 每秒 −25 |
| 空中跨一条车道 | 额外 −25，完成一次 360° 侧翻 |
| 地面、货车顶变道 | 不消耗气量 |
| 飞行高度上限 | 8 m |

气量不足 25 时不能空中变道；一次翻滚结束后才能再次变道。气量耗尽后需要先松开起飞，落地恢复气量后再起飞。

大货车的平顶车厢可以落脚，在车顶行驶同样攒气。离开车厢后会落回路面，高度不够撞上车身也会结束本局。

### 公路上的情况

| 情况 | 观察提示 | 应对方式 |
| --- | --- | --- |
| 前车急刹 | 刹车灯频闪，车头下沉 | 变道或起飞 |
| 后车追尾 | 后方 MPV 持续鸣笛，提示“后方车辆刹车断裂” | 看后视镜，变道或起飞 |
| 邻车弹出电池 | iCAR 风格 SUV 先打双闪急刹，随后弹出电池包 | 避开电池滑入的车道，或起飞 |
| 悬挂断裂 | SUV 风格车辆一角塌下，拖着火花急停 | 变道或起飞 |
| 路边抛锚 | 外侧车道的 SUV 打双闪，车后有三角警示牌 | 提前避让 |
| 普通车辆并线 | 转向灯先闪，再向相邻车道移动 | 留出车距，及时避让 |
| 三辆慢车并排 | 三条车道各有一辆车同速慢行 | 起飞越过 |

五种危险和货车落脚玩法首次遇到时有文字提示，之后主要依靠车灯、火花、喇叭和后视镜判断。普通减速时刹车灯常亮，急刹时才频闪。

车流保留普通轿车、SUV、MPV 风格车辆、大货车和半挂车。随机车流中，普通轿车约占 50%。车辆会跟车刹车、打灯变道，车辆间的碰撞会产生打双闪滑行的事故车，事故车也会挡路。

<details>
<summary>三车并排慢行的生成规则</summary>

开局 15 秒后，每次补充车流有 10% 概率尝试生成一组并排慢车。三辆车分别随机选择现有车型，各占一条车道，保持同速，遇到障碍一起减速。

整组只在 300–360 m 外生成，并检查三条车道的空间、前后车刹车距离及预计接触间隔。抽中后最多等待 5 秒空位，期间暂缓补充普通车辆；仍不安全就跳过。成功生成后至少间隔 22 秒，同时最多一组。

队列行驶期间不主动变道，也不会被改成急刹、弹电池或悬挂断裂事件。玩家通过或队列发生碰撞后，车辆恢复普通车流规则。

## 音乐与声音

主页右上角的圆形音符按钮位于扬声器按钮下方，单独控制背景音乐；扬声器按钮控制游戏音效。两者独立保存开关设置。

音乐统一使用有词版，默认开启，首次点击主页空白处、模式按钮或打开音乐开关后解锁播放。开始游戏也会解锁音乐。各阶段按下面的规则调整，整曲循环：

| 阶段 | 播放内容 | 音量 |
| --- | --- | --- |
| 主页 | 有词版 BGM，返回主页时从头播放 | 20% |
| 开始游戏、再次挑战、暂停页重新开始 | 有词版 BGM，每局从头播放 | 45% |
| 撞车后滑行 | 立即暂停音乐并保留进度，等待结算 | 静音 |
| 结算页面出现 | 有词版 BGM，从撞车前的位置继续播放 | 10% |

撞车后暂停音乐，保留播放位置；结算页出现后降低音量并续播，不重新加载音频。返回主页、开始新一局或重新开始时才从头播放。暂停、继续倒数或切到后台时暂停，恢复后续播；继续游戏不会把 BGM 从头播放。音乐关闭后，以上阶段均保持关闭。音量由独立的 WebAudio 增益控制，不受游戏音效开关影响；WebAudio 不可用时回退到媒体元素音量。**打开主页不会预先下载音乐，音乐关闭时切换页面和开局也不请求音频。**

| 音轨 | 格式 | 文件大小 | 用途 |
| --- | --- | --- | --- |
| [bgm.webm](dist/audio/bgm.webm) | Opus，32 kbps 受限 VBR，48 kHz 立体声 | 约 817 KB | 有词版 BGM 首选 |
| [bgm.m4a](dist/audio/bgm.m4a) | AAC-LC，40 kbps，32 kHz 立体声 | 约 991 KB | 有词版 BGM 备用 |

有词版 BGM 保留原视频中约 3 分 7 秒的完整曲目及已有的短淡入淡出。主页、行驶和结算共用同一音频来源，浏览器按格式支持选择一份，正常播放只下载选中的格式，并使用 `preload="none"` 按需加载。Opus 比上一版约 1.50 MB 的 MP3 小 **45.5%**；AAC 的索引放在文件开头，便于开始播放。WebM 支持与浏览器和系统版本有关，可参考 [WebKit 的格式支持说明](https://webkit.org/blog/15063/webkit-features-in-safari-17-4/)。

## 部署与开发

部署时将 **`dist/` 目录中的全部内容**上传到静态网站托管服务，并保留相对目录结构。无需后端服务和构建步骤。

浏览器需要支持 WebGL 2。Three.js 固定为 **0.180.0**，通过国内 [BootCDN](https://www.bootcdn.cn/three.js/) 加载 min 版（`three.module.min.js` 与 `three.core.min.js`，共约 720 KB），运行时需联网；地址统一在 `dist/index.html` 的 import map 和 modulepreload 中配置。

页面在 `<head>` 中预加载 Three.js 和全部游戏脚本，它们与样式表同时开始下载，不必等上一层脚本下载完才发现下一层依赖。BootCDN 目前对这两个文件既不做 gzip 压缩，也不允许浏览器缓存，所以每次打开都会完整下载；换成 min 版后，下载量比原来的完整版（约 2.0 MB）少 64%。

| 文件 | 职责 |
| --- | --- |
| [dist/index.html](dist/index.html)、[dist/style.css](dist/style.css) | 开始页、HUD、结算页和触屏界面 |
| [dist/game.js](dist/game.js) | 固定步长模拟、燃料、车流、危险与碰撞 |
| [dist/scene.js](dist/scene.js)、[dist/models.js](dist/models.js) | Three.js 场景、车辆、喷气与尾翼动画 |
| [dist/app.js](dist/app.js) | 输入、模式选择、暂停、存储与界面更新 |
| [dist/audio.js](dist/audio.js)、[dist/audio/](dist/audio/) | 游戏音效与独立背景音乐 |
| [tests/](tests/) | 游戏规则测试、加载配置检查及前瞻自动驾驶测试工具 |
| [AGENTS.md](AGENTS.md) | 模块约定、开发与验证注意事项 |
| [THREE-LICENSE.txt](dist/vendor/THREE-LICENSE.txt) | Three.js 的 MIT 许可证 |

最佳成绩、模式、提示和声音偏好保存在当前浏览器。游戏没有账号、广告或后台数据收集。主页与结算页底部均提供仓库和作者 B站链接。

## 测试与验证

安装 Node.js 22 或更新版本，在仓库根目录运行：

```shell
npm test
```

当前共 **66 项测试**，无须安装依赖，覆盖：

- 两种模式的车速、计分、暂停、重开和不同帧率下的一致性。
- 五种危险的预警、碰撞、飞越与变道避让，以及货车顶落脚。
- 空中变道扣气、翻滚锁定、气量耗尽及每秒回气 20 的规则。
- 普通车流比例、并线、事故车，以及并排慢车的生成、刹车距离、等待与解散。
- 多组随机车流的自动驾驶生存检查，以及 30 / 60 / 120 Hz 顶速碰撞防穿透。
- 页面加载配置：使用 min 版 Three.js，Three.js 与全部本地模块都已预加载。

开发时另做过两种模式共 24 局、每局 5 分钟的随机自动驾驶抽查，全部存活，共生成 124 组并排慢车。

音频阶段回归脚本为 `tests/music.browser.mjs`，使用真实 Chromium 媒体播放，检查主页 20%、行驶 45%、结算 10% 的音量、撞车停音与结算续播、返回主页和重开的播放位置，以及格式回退和音乐开关；与 `npm test` 分开运行。可选安装 Playwright 并保持本地服务运行后执行：

```shell
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node tests/music.browser.mjs
```

默认检查 `http://127.0.0.1:4173/`，可用环境变量 `GAME_URL` 指向其他服务，用 `CHROMIUM_EXECUTABLE_PATH` 指定现有 Chromium。

浏览器验证使用桌面 Chromium 的手机尺寸模拟，覆盖双指操作、侧翻、尾喷与尾翼、混合慢车队列、分阶段音乐音量、撞车停音与结算续播、暂停续播与重开、音乐循环、独立声音开关、关闭音乐时无音频请求、底部链接布局等。音频通过全曲严格解码，AAC 回退通过模拟首选格式不受支持的场景检查，音频缺失也不阻塞结算。真实手机性能和 Safari 真机播放仍需单独测试。
