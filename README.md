# Roadster · 公路飞跃

手机竖屏网页小游戏：白天三车道高速公路、滑动变道、喷气起飞躲避危险。

## 怎么玩

- 在画面左右滑动切换一条车道；按住底部按钮起飞，松手降落。支持同时滑动与起飞。电脑方向键或 A/D 变道，空格起飞。
- 地面自动攒气，喷气持续耗气。气量耗尽后松手，落地恢复。
- 危险都来自路上的车：前车亮起刹车灯急刹、后方刹车失灵的车鸣笛冲来（看后视镜）、邻车双闪急停后弹出电池包。平均三四秒就来一次，有时前后两个接连而来。每种情况第一次出现时有一句提示，之后只能看车灯、听喇叭、看后视镜判断。普通车也会打转向灯并线到你前方。
- 从 140 km/h 起步，约 30 秒突破 300 km/h，之后逐渐逼近 400 km/h；车速越高，镜头越广、风线越密、风声越响。飞行上限 8 m。普通车流会自己变道、跟车刹车；车辆之间会真实碰撞，刹车失灵的车撞上前车后两车打着双闪滑行撞停，事故车也会成为障碍。每行驶 10 m 得 1 分，无限时长。
- 切换后台自动暂停。最佳距离与静音设置保存在当前浏览器。

车型外观为风格化参考，危险事件为虚构游戏设定。

## 本地运行

安装 Python 后，在本文件所在目录运行：

```text
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

在浏览器访问 http://127.0.0.1:4173/ 。ES 模块需要 HTTP 服务，不能直接双击 HTML 文件运行。部署只需上传 dist 目录中的静态文件，无须构建。Three.js 通过国内 [BootCDN](https://www.bootcdn.cn/three.js/) 加载，运行时需联网。

Three.js 固定为 0.180.0，统一在 `dist/index.html` 的 import map 中配置。主模块和其依赖的 `three.core.js` 均从同一 CDN、同一版本加载。

## 文件

- `dist/game.js`：固定步长模拟、起降与燃料、危险生成和碰撞。
- `dist/scene.js`、`dist/models.js`：三维场景、车辆和后视镜。
- `dist/app.js`、`dist/audio.js`：触屏界面、暂停、记录和声音。
- `dist/vendor/THREE-LICENSE.txt`：Three.js 的 MIT 许可证。
- `tests/game-v2.test.mjs`：游戏规则测试，运行 `node --test tests/game-v2.test.mjs`。

浏览器需支持 WebGL 2。没有账号、广告或后台数据收集。


## 验证

`npm test` 共 27 项规则测试，包括每种危险的地面碰撞、飞越和变道避让，信号到接触的时间，车辆间碰撞与滑行停车，司机绕开事故车，普通车打灯并线且留足反应时间，撞车后的滑行，新车只在远处出现，以及 12 组随机车流在高车速下各 3 分钟的自动驾驶。另用 48 局、每局 5 分钟的自动驾驶抽查（一半从最高速开局），全部存活。浏览器在桌面 Chromium 的手机尺寸模拟（390×844、375×667）中检查过画面，尚未在真实手机上测试性能。
